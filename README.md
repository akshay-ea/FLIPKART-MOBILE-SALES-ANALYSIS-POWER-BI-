# 📱 Flipkart Mobile Sales Analysis – Power BI

## 📌 Project Overview
This project focuses on analyzing Flipkart mobile sales data using Microsoft Power BI. An interactive dashboard was developed to explore mobile brands, prices, ratings, colors, storage, and memory.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- CSV Dataset

## 📂 Project Files
- `Flipkart_Mobiles G.csv` – Raw dataset
- `power bi project G.pbix` – Power BI dashboard file
- `power bi project G.docx` – Project documentation

## 📊 Dashboard Features
- Selling Price Analysis by Brand
- Average Original Price by Brand
- Mobile Models by Color
- Customer Rating Analysis
- Color Distribution by Brand
- Selling Price Analysis by Storage
- Brand and Memory Analysis

## 🎯 Project Objectives
- Analyze mobile pricing across different brands.
- Explore mobile features and specifications.
- Understand rating distribution.
- Build an interactive dashboard for data exploration.
